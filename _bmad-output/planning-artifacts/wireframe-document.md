# 线框图文档 - AI 爬虫框架

**基于 UX 设计规范 v1.0**

---

## 文档说明

本文档包含 AI 爬虫框架的所有屏幕线框图，用于指导前端开发和 UI 设计实现。

**线框图类型：**
- 低保真线框图：布局和结构
- 中保真线框图：组件和交互
- 高保真线框图：视觉和样式（待设计）

**设计原则：**
- 零代码优先
- AI 透明可见
- 渐进式能力
- 即时反馈即信任

**技术栈：**
- 前端框架：Vue.js 3.4+
- UI 组件库：Naive UI
- 桌面框架：Electron
