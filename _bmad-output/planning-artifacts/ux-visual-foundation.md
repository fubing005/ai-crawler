**视觉基础设计（Visual Foundation）建立产品的视觉语言**

## 3.1 Color System

### 核心颜色方案

**主色调色（Primary Color）**
- **主色**：`#3182CE`（专业蓝）
  - 用途：主要操作按钮、链接、选中状态
  - 心理感受：专业、可靠、信任
  - 对比度：与白色背景 4.8:1（符合WCAG AA标准）

- **主色悬停**：`#2A6FBA`
  - 用途：按钮和链接的悬停状态
  - 视觉反馈：深 10%，提供清晰的交互反馈

- **主色激活**：`#2258A0`
  - 用途：按钮的按压/点击状态
  - 视觉反馈：再深 10%，确认用户操作

**辅助色（Secondary Color）**
- **辅助色**：`#805AD5`（智慧紫）
  - 用途：次要操作、标签、装饰元素
  - 心理感受：智能、创新、科技
  - 对比度：与白色背景 4.5:1（符合WCAG AA标准）

### 功能色系

**成功色（Success）**
- **主成功色**：`#10B981`
  - 用途：成功消息、完成状态、正常指示
  - 心理感受：积极、完成、安全
  - 对比度：3.7:1（符合WCAG AA标准）

- **成功背景**：`#D1FAE5`（浅绿背景）
  - 用途：成功消息的背景、状态标签背景
  - 对比度：确保文本可读

**警告色（Warning）**
- **主警告色**：`#F59E0B`
  - 用途：警告消息、需要注意的状态
  - 心理感受：注意、提示、温和
  - 对比度：3.9:1（符合WCAG AA标准）

- **警告背景**：`#FEF3C7`（浅黄背景）
  - 用途：警告消息的背景

**错误色（Error）**
- **主错误色**：`#EF4444`
  - 用途：错误消息、失败状态、危险操作
  - 心理感受：错误、危险、停止
  - 对比度：4.5:1（符合WCAG AA标准）

- **错误背景**：`#FEE2E2`（浅红背景）
  - 用途：错误消息的背景

**信息色（Info）**
- **主信息色**：`#3B82F6`
  - 用途：信息提示、帮助文本、说明
  - 心理感受：信息、帮助、中性
  - 对比度：4.5:1（符合WCAG AA标准）

### 中性色系

**浅色模式中性色**
- **背景**：`#FFFFFF`
- **卡片**：`#F7FAFC`
- **边框**：`#E2E8F0`
- **文本主**：`#1A202C`
- **文本次**：`#4A5568`
- **文本禁用**：`#A0AEC0`

**深色模式中性色**
- **背景**：`#1A202C`
- **卡片**：`#2D3748`
- **边框**：`#4A5568`
- **文本主**：`#F7FAFC`
- **文本次**：`#A0AEC0`

## 3.2 Typography System

### 字体选择

**主字体（Primary Font）**
- **字体名称**：Inter
- **字体分类**：无衬线字体（Sans-Serif）
- **选择理由**：
  - 现代、干净、专业
  - 优秀的可读性，适合数字界面
  - 多字重支持（300-700）
  - 良好的屏幕显示优化
  - 广泛使用的系统字体，加载快速

**字体栈：**
```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', 
             'Roboto', 'Helvetica Neue', Arial, sans-serif;
```

**等宽字体（Monospace Font）**
- **字体名称**：JetBrains Mono
- **字体分类**：等宽字体（Monospace）
- **选择理由**：
  - 专为代码和IDE设计
  - 区分性高（0/O, 1/l/l, i/I）
  - 优秀的可读性
  - 现代科技感
  - 适合显示CSS选择器、JSON数据等

**字体栈：**
```css
font-family: 'JetBrains Mono', 'Fira Code', 'Courier New', 
             monospace;
```

### 字号层级（Type Scale）

采用 1.25 倍递增的模块化比例：

| 名称 | 字号 | 行高 | 字重 | 用途 |
|------|:-----:|:-----:|:-----:|------|
| h1 | 32px | 48px (1.5) | 600 | 页面主标题 |
| h2 | 26px | 39px (1.5) | 600 | 章节标题 |
| h3 | 21px | 31.5px (1.5) | 600 | 子章节标题 |
| h4 | 17px | 25.5px (1.5) | 500 | 卡片标题、标签 |
| body | 14px | 23.8px (1.7) | 400 | 正文内容 |
| small | 12px | 18px (1.5) | 400 | 辅助文本、注脚 |
| tiny | 10px | 15px (1.5) | 400 | 极小文本（如角标） |

### 字重（Font Weights）

- **300**：Light - 用于装饰性文本
- **400**：Regular - 用于正文、标签
- **500**：Medium - 用于小标题、强调文本
- **600**：Semi-Bold - 用于主标题、按钮文本
- **700**：Bold - 用于强强调（慎用）

### 字间距（Letter Spacing）

- **标题**：0% 到 -0.5%（紧凑感）
- **正文**：-0.5%（略微紧凑，提高可读性）
- **代码和技术文本**：0%（保持等宽）
- **大写标题**：0.5%（增加间距，提高可读性）

## 3.3 Spacing & Layout Foundation

### 间距系统（Spacing System）

**基础间距单位：8px**

所有间距都基于 8px 的倍数，确保一致性：

| 名称 | 值 | 用途 |
|------|:----:|------|
| space-0 | 0px | 无间距 |
| space-1 | 8px | 元素间最小间距 |
| space-2 | 16px | 组件间标准间距 |
| space-3 | 24px | 区域间间距 |
| space-4 | 32px | 大区域间距 |
| space-5 | 48px | 页面级间距 |
| space-6 | 64px | 章节级间距 |
| space-7 | 96px | 页面顶部/底部大间距 |

### 组件内边距（Component Padding）

- **小型组件**（按钮、标签）：`8px 16px`
- **中型组件**（卡片、输入框）：`16px 24px`
- **大型组件**（面板、对话框）：`24px 32px`
- **模态框**：`32px 48px`

### 网格系统（Grid System）

**12 列网格布局**

- **最大宽度**：1200px（适合桌面显示）
- **列数**：12 列
- **间距**：24px
- **边距**：16px

**断点（Breakpoints）：**
- **移动端**：< 640px
- **平板**：640px - 1024px
- **桌面**：1024px - 1280px
- **大屏**：> 1280px

### 布局模式（Layout Patterns）

**1. 左-中-右三栏布局（Postman 风格）**
```
┌─────────┬─────────────────┬─────────┐
│ 左侧栏  │   主工作区     │ 右侧栏  │
│  240px  │     自适应     │  320px  │
└─────────┴─────────────────┴─────────┘
```

- **左侧栏**：任务列表、模板库、历史记录
- **主工作区**：页面预览、元素选择、配置编辑
- **右侧栏**：采集结果、数据预览、日志信息

**2. 主工作区 + 右侧面板（简化布局）**
```
┌─────────────────────┬─────────┐
│     主工作区       │ 右侧栏  │
│       自适应       │  320px  │
└─────────────────────┴─────────┘
```

- **主工作区**：页面预览、元素选择、配置编辑
- **右侧栏**：可折叠，显示采集结果、日志等

**3. 单栏全宽布局**
```
┌─────────────────────────────────┐
│         主工作区             │
│           自适应              │
└─────────────────────────────────┘
```

- **使用场景**：欢迎页、首次使用向导、全屏预览

## 3.4 Accessibility Considerations

### 可访问性目标

**符合 WCAG 2.1 AA 标准**

### 键盘导航

**完整的键盘支持：**

- **Tab 键**：按逻辑顺序遍历所有可交互元素
- **Shift + Tab**：反向遍历
- **Enter / Space**：激活按钮和链接
- **Escape**：关闭模态框、取消操作
- **箭头键**：在列表、菜单中导航
- **Home / End**：跳转到列表开头/结尾

**焦点管理：**

- **焦点大小**：最小 44x44 像素（触摸友好）
- **焦点间距**：最小 8px（视觉清晰）
- **焦点样式**：清晰可见的焦点环

```css
:focus-visible {
  outline: 2px solid #3182CE;
  outline-offset: 2px;
}
```

### 屏幕阅读器支持

**语义化 HTML：**

- 使用正确的 HTML 元素（`<nav>`, `<main>`, `<article>`, `<aside>`）
- 正确的标题层级（h1 → h2 → h3）
- 表单元素关联标签（`for` 属性）

**ARIA 属性：**

- `aria-label`：为无文本标签的元素提供可访问名称
- `aria-describedby`：关联描述性文本
- `aria-live="polite"`：动态内容更新通知
- `aria-expanded`：展开/折叠状态
- `role="status"`：状态指示

### 对比度

**文本对比度：**

- **常规文本**：最小 4.5:1（WCAG AA）
- **大文本（≥18pt 或 14pt 粗体）**：最小 3:1（WCAG AA）
- **UI 组件**：最小 3:1（图标、边框）

**已验证的对比度：**

- 白色背景 + 蓝色按钮（#3182CE）：4.8:1 ✅
- 浅灰背景（#F7FAFC）+ 主文本（#1A202C）：7.2:1 ✅
- 浅绿背景（#D1FAE5）+ 成功文本（#10B981）：4.5:1 ✅
- 浅黄背景（#FEF3C7）+ 警告文本（#F59E0B）：4.5:1 ✅
- 浅红背景（#FEE2E2）+ 错误文本（#EF4444）：4.5:1 ✅

### 颜色盲友好

**不依赖颜色传递信息：**

- 状态指示使用图标 + 颜色（如 ✗ 红色，✓ 绿色）
- 错误消息使用边框 + 图标 + 颜色
- 必填字段使用 * 符号 + 红色边框

### 动画和动态效果

**尊重用户偏好：**

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

**动画时长限制：**

- **微动画**（按钮悬停）：≤ 200ms
- **标准动画**（模态框打开）：200-300ms
- **复杂动画**（页面过渡）：≤ 500ms

### 可访问性检查清单

- ✅ 所有交互元素可通过键盘访问
- ✅ 焦点顺序符合逻辑
- ✅ 所有文本对比度 ≥ 4.5:1
- ✅ 所有图片有 `alt` 文本或 `aria-label`
- ✅ 表单元素有关联的标签
- ✅ 错误消息清晰且可修复
- ✅ 动态内容更新通过 `aria-live` 通知
- ✅ 模态框可关闭且焦点正确管理
- ✅ 尊重用户的动画偏好设置
- ✅ 支持屏幕阅读器

## 视觉基础设计总结

**关键决策：**
- **色彩方案**：蓝色系（#3182CE）传达专业和信任感
- **字体选择**：Inter（正文）+ JetBrains Mono（代码），现代且可读
- **间距系统**：8px 基础单位，确保一致性
- **布局模式**：三栏布局（Postman 风格），适合复杂工具
- **可访问性**：符合 WCAG AA 标准，完整的键盘和屏幕阅读器支持

**设计原则：**
- 一致性：所有间距、颜色、字号遵循系统规则
- 可访问性：优先考虑键盘导航、屏幕阅读器、对比度
- 可读性：字号、行高、字间距确保文本易于阅读
- 现代感：扁平化设计、简洁的视觉语言
- 专业感：蓝色系传递专业和可靠性
