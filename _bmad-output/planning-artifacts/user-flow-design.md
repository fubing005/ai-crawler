# 用户流程设计文档 - AI 爬虫框架

**基于 UX 设计规范 v1.0 和 Figma 线框图**

---

## 文档说明

本文档定义了 AI 爬虫框架的所有关键用户流程，包括用户旅程、交互状态、页面转换和错误处理。这些流程将指导交互原型的实现。

**设计原则：**
- 零代码优先 - 新手用户无需编程知识
- AI 透明可见 - 用户理解 AI 的判断和不确定性
- 渐进式能力 - 从简单到复杂的功能递进
- 即时反馈即信任 - 每个操作都有清晰的视觉反馈

---

## 用户旅程概览

| 旅程编号 | 旅程名称 | 目标用户 | 复杂度 | 优先级 |
|---------|---------|---------|--------|--------|

## 关键用户流程

### 流程 1: 首次使用流程（新手用户）

**流程描述：** 用户首次启动应用，完成初始配置，成功爬取第一个网站

**涉及屏幕：** 屏幕 1-5 → 屏幕 6 → 屏幕 9 → 屏幕 10

**流程步骤：**

```
启动应用
  ↓
检测首次使用
  ↓
屏幕 1: 欢迎向导 - 步骤 1/5
  ├─ 显示欢迎信息
  ├─ 展示 3 个示例网址
  └─ [跳过向导] [下一步]
  ↓
屏幕 2: 欢迎向导 - 步骤 2/5
  ├─ 选择 AI 模型类型（本地/云端）
  ├─ 配置模型参数
  ├─ 测试连接
  └─ [上一步] [下一步]
  ↓
屏幕 3: 欢迎向导 - 步骤 3/5
  ├─ 选择网址来源（示例/自定义）
  ├─ 输入或选择网址
  └─ [上一步] [下一步]
  ↓
屏幕 4: 欢迎向导 - 步骤 4/5
  ├─ AI 分析页面结构
  ├─ 显示识别的字段和置信度
  └─ [上一步] [下一步]
  ↓
屏幕 5: 欢迎向导 - 步骤 5/5
  ├─ 确认配置和字段
  ├─ 开始爬取
  └─ [上一步] [完成]
  ↓
屏幕 9: AI 分析预览界面
  ├─ 显示分析结果
  ├─ 字段选择和编辑
  └─ [重新分析] [开始爬取] [取消]
  ↓
屏幕 10: 数据预览和导出界面
  ├─ 显示爬取结果
  ├─ 数据表格预览
  └─ [导出为 JSON] [导出为 CSV] [导出为 Excel]
  ↓
庆祝动画 + 数据统计
  ↓
屏幕 6: 主界面 - 简洁视图
```

**关键交互点：**

1. **步骤指示器** - 显示当前步骤（1/5），提供进度感知
2. **模型选择** - 本地模型 vs 云端模型，影响后续配置
3. **连接测试** - 实时反馈连接状态，失败时提供错误信息
4. **字段确认** - 用户可以调整 AI 识别的字段
5. **庆祝动画** - 首次成功时的正向反馈

**错误处理：**

- **模型连接失败** - 显示错误原因，提供重试按钮
- **网址无效** - 实时验证，显示格式错误提示
- **AI 分析失败** - 显示详细错误日志，提供重新分析选项
- **爬取失败** - 显示失败原因，提供重试或跳过选项

### 流程 2: 常规爬取流程（已配置用户）

**流程描述：** 已配置用户输入网址，AI 分析并爬取数据

**涉及屏幕：** 屏幕 6 → 屏幕 9 → 屏幕 10

**流程步骤：**

```
屏幕 6: 主界面 - 简洁视图
  ├─ 输入网址
  ├─ [开始分析]
  └─ [最近爬取] [视图切换]
  ↓
网址验证
  ├─ 有效 → 继续
  └─ 无效 → 显示错误提示
  ↓
屏幕 9: AI 分析预览界面
  ├─ AI 分析页面结构
  ├─ 显示进度: 分析中
  ├─ 显示识别的字段列表
  │   ├─ 字段名称
  │   ├─ 预览值
  │   ├─ 置信度
  │   └─ [☑] 选择框
  ├─ [全选] [取消全选] [添加字段] [编辑字段]
  └─ [重新分析] [开始爬取] [取消]
  ↓
字段确认
  ├─ 确认 → 开始提取数据
  └─ 调整 → 字段编辑对话框
  ↓
数据提取
  ├─ 显示进度: 提取中
  └─ 实时更新进度条
  ↓
屏幕 10: 数据预览和导出界面
  ├─ 显示数据表格预览
  ├─ 显示准确率统计
  ├─ [搜索] [筛选] [排序] [导出] [编辑] [删除]
  ├─ 分页器: [上一页] 1/16 [下一页]
  └─ [导出为 JSON] [导出为 CSV] [导出为 Excel]
  ↓
导出成功
  ├─ 显示成功通知
  └─ 保存到历史记录
  ↓
返回屏幕 6
```

**关键交互点：**

1. **实时网址验证** - 输入时即时验证格式
2. **AI 分析进度** - 显示当前步骤和估计时间
3. **字段选择** - 默认全选，支持单选和全选
4. **内联编辑** - 字段可直接在表格中编辑
5. **实时预览** - 数据提取时实时显示结果

**优化方案：**

- **智能默认** - 基于历史数据推荐字段选择
- **批量操作** - 支持同时编辑多个字段
- **快捷键** - Ctrl+A 全选，Ctrl+D 取消全选
- **准确率可视化** - 显示置信度分布图

### 流程 3: 批量爬取流程（高级用户）

**流程描述：** 用户添加多个 URL，一次性批量爬取多个网站

**涉及屏幕：** 屏幕 7 → 屏幕 9 → 屏幕 10

**流程步骤：**

```
屏幕 7: 主界面 - 仪表板视图
  ├─ 点击 [批量爬取]
  └─ 显示批量爬取对话框
  ↓
批量爬取对话框
  ├─ 添加 URL
  │   ├─ 手动输入
  │   ├─ 导入文件
  │   └─ 从剪贴板粘贴
  ├─ 全局配置
  │   ├─ 并发数: [5]
  │   ├─ 超时: [30s]
  │   ├─ 重试: [3]
  │   └─ 全局字段模板
  ├─ URL 列表
  │   ├─ 显示所有 URL
  │   ├─ 状态指示（等待/运行/完成/失败）
  │   └─ [删除] [上移] [下移]
  └─ [开始批量爬取] [取消]
  ↓
批量执行
  ├─ 显示总体进度
  ├─ 显示单个任务状态
  ├─ 实时更新任务队列
  └─ 支持暂停/恢复
  ↓
任务完成
  ├─ 显示汇总统计
  │   ├─ 总任务数
  │   ├─ 成功数
  │   ├─ 失败数
  │   └─ 总数据量
  ├─ 失败任务重试
  └─ [导出所有结果] [查看详情]
  ↓
屏幕 10: 数据预览和导出界面
  ├─ 显示所有任务结果
  └─ 支持合并导出
```

**关键交互点：**

1. **URL 批量导入** - 支持多种导入方式
2. **全局配置** - 一次配置，应用到所有任务
3. **实时监控** - 显示每个任务的执行状态
4. **失败重试** - 自动或手动重试失败任务
5. **结果汇总** - 统计所有任务的执行结果

**高级功能：**

- **智能调度** - 根据网站类型调整爬取策略
- **资源限制** - 控制并发数，避免过载
- **断点续传** - 支持暂停后继续执行
- **结果合并** - 自动合并相同结构的数据

### 流程 7: 错误处理和恢复流程

**流程描述：** 当用户遇到错误时，提供清晰的错误信息和可操作的解决步骤

**涉及屏幕：** 所有屏幕

**流程步骤：**

```
任务执行中
  ↓
错误发生
  ↓
显示错误通知
  ├─ 错误类型
  ├─ 错误消息
  ├─ 影响范围
  └─ [查看详情] [忽略] [重试]
  ↓
错误详情对话框
  ├─ 错误信息
  │   ├─ 错误代码
  │   ├─ 错误描述
  │   ├─ 发生时间
  │   └─ 相关任务
  ├─ 错误原因
  │   ├─ 技术原因
  │   └─ 用户原因
  ├─ 解决步骤
  │   ├─ 步骤 1: ...
  │   ├─ 步骤 2: ...
  │   └─ 步骤 3: ...
  ├─ 相关资源
  │   ├─ 文档链接
  │   ├─ 常见问题
  │   └─ 联系支持
  └─ [一键重试] [修改配置] [联系支持] [关闭]
  ↓
用户选择操作
  ├─ 一键重试
  │   ├─ 自动应用修复
  │   ├─ 重新执行任务
  │   └─ 显示重试结果
  ├─ 修改配置
  │   ├─ 打开配置界面
  │   ├─ 修改相关设置
  │   └─ 重新执行任务
  ├─ 联系支持
  │   ├─ 生成错误报告
  │   ├─ 发送到支持团队
  │   └─ 显示支持工单号
  └─ 关闭
      └─ 记录错误日志
```

**关键交互点：**

1. **友好错误信息** - 使用用户友好的语言
2. **可操作的解决步骤** - 提供具体的解决方法
3. **一键重试** - 自动应用修复并重试
4. **错误报告** - 生成详细的错误报告
5. **支持联系** - 快速联系技术支持

**错误类型：**

- **网络错误** - 连接超时、DNS 解析失败
- **API 错误** - API Key 无效、配额超限
- **数据错误** - 数据格式错误、字段缺失
- **系统错误** - 内存不足、磁盘空间不足
- **用户错误** - 输入错误、权限不足

### 流程 8: 离线模式流程

**流程描述：** 用户在网络断开时使用系统，查看历史数据，管理离线队列，网络恢复后自动同步

**涉及屏幕：** 屏幕 11

**流程步骤：**

```
主界面 - 在线模式
  ↓
网络状态检测
  ├─ 网络正常 → 继续在线模式
  └─ 网络断开 → 切换到离线模式
  ↓
显示离线模式通知
  ├─ 离线模式徽章
  ├─ 最后同步时间
  └─ 队列任务数
  ↓
屏幕 11: 离线模式界面
  ├─ 离线队列面板
  │   ├─ 显示队列任务
  │   │   ├─ 任务 ID
  │   │   ├─ 网址
  │   │   ├─ 状态: 等待中
  │   │   ├─ 优先级
  │   │   └─ [删除] [上移] [下移]
  │   └─ [清空队列] [立即执行(需网络)]
  ├─ 本地数据面板
  │   ├─ 显示本地数据
  │   │   ├─ 数据源名称
  │   │   ├─ 爬取时间
  │   │   ├─ 数据量
  │   │   ├─ 准确率
  │   │   └─ [查看] [导出] [删除]
  │   └─ [搜索] [筛选] [导出]
  └─ 离线功能说明
      ├─ 可用功能列表
      └─ 不可用功能列表
  ↓
离线操作
  ├─ 查看历史数据 ✓
  ├─ 搜索和筛选 ✓
  ├─ 导出本地数据 ✓
  ├─ 管理离线队列 ✓
  ├─ 新建爬取任务 ✗
  ├─ AI 分析 ✗
  └─ 在线功能 ✗
  ↓
网络恢复检测
  ├─ 自动检测网络恢复
  ├─ 显示恢复通知
  └─ 询问是否执行队列
  ↓
执行队列任务
  ├─ 按优先级执行
  ├─ 显示执行进度
  └─ 更新任务状态
  ↓
切换回在线模式
  ├─ 启用所有功能
  ├─ 同步最新数据
  └─ 显示在线模式徽章
```

**关键交互点：**

1. **自动检测** - 自动检测网络状态变化
2. **状态通知** - 清晰显示当前模式
3. **功能标识** - 标注可用和不可用功能
4. **队列管理** - 管理离线任务队列
5. **自动同步** - 网络恢复后自动执行队列

**离线功能：**

- **本地数据访问** - 查看和导出本地数据
- **历史记录** - 查看所有历史爬取记录
- **搜索和过滤** - 在本地数据中搜索
- **队列管理** - 添加、删除、调整队列任务
- **配置管理** - 修改本地配置

**状态持久化：**

- **离线状态保存** - 应用关闭后保存离线状态
- **队列持久化** - 队列任务保存到本地数据库
- **数据缓存** - 缓存常用数据
- **配置同步** - 网络恢复后同步配置

## 原型实现建议

### 1. 使用 Figma Prototype 功能

**优势：**
- 无需编码，快速创建交互原型
- 支持多种交互类型（点击、悬停、拖拽）
- 可以直接在 Figma 中测试和演示
- 支持团队协作和反馈

**实现步骤：**

1. **创建连接**
   - 在 Figma 中选择要连接的元素
   - 点击原型面板中的 "连接" 按钮
   - 拖动到目标页面或框架

2. **设置交互**
   - 选择交互类型（点击、悬停、拖拽）
   - 设置动画效果（淡入、滑动、缩放）
   - 设置动画持续时间

3. **创建智能动画**
   - 使用相同的图层名称
   - Figma 自动创建过渡动画
   - 适用于复杂的状态转换

### 2. 使用 Figma Components 和 Variants

**优势：**
- 创建可复用的组件
- 管理组件的不同状态
- 保持设计一致性
- 简化原型维护

**实现步骤：**

1. **创建组件**
   - 选择要转换为组件的元素
   - 右键点击 → "Create component"
   - 命名组件（使用命名规范）

2. **创建变体**
   - 复制组件
   - 修改状态（正常、悬停、禁用）
   - 添加到变体集

3. **使用组件**
   - 从组件库拖入组件
   - 选择需要的变体
   - 连接交互

### 3. 使用 Figma Interactive Components

**优势：**
- 创建真正的交互式原型
- 支持复杂的状态管理
- 无需多个页面
- 更接近真实产品体验

**实现步骤：**

1. **创建交互式组件**
   - 创建组件变体（不同状态）
   - 设置交互逻辑
   - 测试交互效果

2. **设置交互逻辑**
   - 选择触发元素
   - 设置动作（更改变体）
   - 设置条件（可选）

3. **测试原型**
   - 点击 "Play" 按钮
   - 测试所有交互
   - 调整交互逻辑
