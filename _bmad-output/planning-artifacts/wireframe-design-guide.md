## 设计系统基础

### 颜色系统

## Figma 创建步骤

### 步骤 1：创建项目结构

1. **打开 Figma**，创建新文件
2. **重命名文件**：`AI 爬虫 - 线框图设计`
3. **创建页面结构**：
   - 在左侧面板点击 `+` 创建新页面
   - 创建以下页面：
     - `01-首次使用向导`
     - `02-主界面`
     - `03-新建爬虫流程`
     - `04-数据预览和导出`
     - `05-设置和历史`

### 步骤 2：设置设计系统

1. **创建局部样式**：
   - 在右侧面板选择 `Local Styles`
   - 创建颜色样式
   - 创建文字样式
   - 创建网格和布局样式

2. **创建组件库**：
   - 按钮
   - 输入框
   - 卡片
   - 导航栏
   - 进度条
   - 表格

### 步骤 3：创建基础组件

1. **按钮组件**：
   - 主按钮：背景 `#3182CE`，白色文字
   - 次要按钮：背景白色，`#3182CE` 边框
   - 大小：Large (48px), Medium (40px), Small (32px)

2. **输入框组件**：
   - 高度：`48px`
   - 边框：`1px solid #E2E8F0`
   - 圆角：`4px`
   - 占位符颜色：`#A0AEC0`

3. **卡片组件**：
   - 背景：`#FFFFFF`
   - 圆角：`12px`
   - 阴影：`0 4px 6px -1px rgba(0, 0, 0, 0.1)`
   - 内边距：`24px`

### 步骤 4：创建画板

1. **首次使用向导**：
   - 创建 `1200px × 800px` 画板
   - 应用导航栏组件
   - 创建步骤指示器
   - 创建主内容卡片
   - 添加欢迎图标和文字
   - 添加操作按钮

2. **主界面**：
   - 创建 `1400px × 900px` 画板
   - 应用导航栏组件
   - 创建模式切换器
   - 创建快速操作区域
   - 创建最近活动列表
   - 创建 AI 智能推荐面板

3. **新建爬虫流程**：
   - 创建多个画板：网址输入、AI 分析、数据预览
   - 使用一致的顶部导航栏
   - 应用步骤指示器
   - 创建内容卡片

### 步骤 5：添加交互和状态

1. **创建变体**：
   - 按钮的悬停状态、按下状态、禁用状态
   - 输入框的聚焦状态、错误状态
   - 卡片的悬停状态

2. **添加原型链接**：
   - 连接步骤指示器到不同画板
   - 连接按钮到下一个画板
   - 添加过渡动画

## 布局和间距规范

### 水平间距

| 用途 | 间距 | 说明 |
|------|------|------|
| 卡片内边距 | 24px | 卡片内容与边缘的距离 |
| 按钮内边距 | 12px | 按钮文字与边缘的距离 |
| 输入框内边距 | 16px | 输入框文字与边缘的距离 |
| 表格单元格间距 | 12px | 表格单元格内边距 |
| 导航项间距 | 32px | 导航菜单项之间的间距 |
| 按钮组间距 | 16px | 相关按钮之间的间距 |

### 垂直间距

| 用途 | 间距 | 说明 |
|------|------|------|
| 页面顶部间距 | 32px | 内容与顶部的距离 |
| 卡片组间距 | 24px | 卡片之间的垂直间距 |
| 表单字段间距 | 16px |`表单字段之间的间距 |
| 列表项间距 | 8px | 列表项之间的间距 |
| 段落间距 | 16px | 段落之间的间距 |
| 章节间距 | 48px | 主要章节之间的间距 |
