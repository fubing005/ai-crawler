# Epic 1: 用户认证和系统配置 - Stories

## Epic 概述

**目标：** 用户可以安装应用、配置 AI 模型提供商、设置系统偏好，并开始使用产品。

**用户成果：**
- 完成应用安装和首次设置
- 配置本地（Ollama）和云端（OpenAI、Anthropic、Qwen 等）AI 模型提供商
- 设置模型优先级和参数
- 配置隐私和安全设置
- 启用数据脱敏选项
- 访问 CLI 接口进行高级操作

**FRs 覆盖：** FR11-FR28, FR29, FR35, FR36, FR86-FR91

**技术备注：**
- 统一 AI 模型抽象层支持多提供商
- 自动回退机制和成本追踪
- 设置向导引导用户首次配置
- 本地数据存储和 AES-256 加密
- RBAC 和审计日志

**依赖关系：** 无（基础 Epic）

---

## Stories

### Story 1.1: 首次设置向导

作为新用户，
我希望看到引导式设置向导，
这样我就能快速完成初始配置并开始使用产品。

**Acceptance Criteria:**

**Given** 用户首次启动应用
**When** 应用检测到没有已保存的配置
**Then** 系统显示设置向导欢迎页面
**And** 欢迎页面说明产品核心功能和设置步骤
**And** 用户可以点击"下一步"继续设置
**And** 用户可以选择跳过设置向导（跳过后将使用默认配置）

**Given** 用户在设置向导中
**When** 用户点击"下一步"按钮
**Then** 系统导航到下一个设置步骤
**And** 显示当前步骤的进度指示器（例如：步骤 1/5）
**And** 用户可以点击"上一步"返回前一设置步骤

**Given** 用户在设置向导中
**When** 用户点击"取消"或"跳过设置"按钮
**Then** 系统确认用户是否要跳过设置
**And** 确认后保存默认配置并导航到主界面

**相关需求：** FR29（桌面应用访问）

---

### Story 1.2: 配置本地 AI 模型提供商（Ollama）

作为用户，
我希望能够配置本地 Ollama 模型提供商，
这样我就能使用本地部署的 AI 模型进行页面分析和数据提取，保持数据隐私。

**Acceptance Criteria:**

**Given** 用户在设置向导的 AI 模型配置步骤中
**When** 用户选择"添加本地模型提供商"选项
**Then** 系统显示 Ollama 配置表单
**And** 表单包含必填字段：模型名称、API 端点（默认值：http://localhost:11434）
**And** 用户可以测试连接以验证 Ollama 是否正常运行

**Given** 用户填写 Ollama 配置表单
**When** 用户点击"测试连接"按钮
**Then** 系统尝试连接到指定的 Ollama 端点
**And** 如果连接成功，显示成功消息并列出可用的模型列表
**And** 如果连接失败，显示错误消息和建议（例如：确认 Ollama 服务已启动）
**And** 连接测试在 10 秒内完成或超时

**Given** 用户测试 Ollama 连接成功
**When** 用户点击"保存配置"按钮
**Then** 系统保存 Ollama 提供商配置到本地配置文件
**And** 使用 AES-256 加密敏感配置信息
**And** 配置在主界面"AI 模型设置"中可见
**And** 系统记录配置操作到审计日志

**相关需求：** FR12（添加本地模型提供商）、FR24（测试 AI 模型连接）、FR87（敏感数据加密）、FR89（审计日志）

---

### Story 1.3: 配置云端 AI 模型提供商

作为用户，
我希望能够添加并配置云端 AI 模型提供商（OpenAI、Anthropic、Qwen、Doubao、GLM、Google Gemini），
这样我就能使用强大的云端模型进行复杂的页面分析和数据提取任务。

**Acceptance Criteria:**

**Given** 用户在"AI 模型设置"界面
**When** 用户点击"添加云端模型提供商"按钮
**Then** 系统显示模型提供商选择对话框
**And** 对话框列出所有支持的云端提供商选项（OpenAI、Anthropic、Qwen、Doubao、GLM、Google Gemini）
**And** 每个选项显示提供商名称和图标

**Given** 用户选择一个云端模型提供商（例如：OpenAI）
**When** 系统显示提供商配置表单
**Then** 表单包含必填字段：API Key、Base URL（可选，默认使用提供商官方端点）
**And** 表单包含可选字段：模型名称（如果提供商支持多模型）
**And** 表单显示提供商的 API Key 获取链接和文档链接

**Given** 用户填写云端模型提供商配置
**When** 用户点击"测试连接"按钮
**Then** 系统使用提供的 API Key 测试连接到提供商 API
**And** 如果 API Key 有效，显示成功消息并测试模型可用性
**And** 如果 API Key 无效或网络错误，显示具体错误消息
**And** 连接测试在 10 秒内完成或超时

**Given** 用户测试云端配置成功
**When** 用户点击"保存配置"按钮
**Then** 系统保存云端提供商配置到本地配置文件
**And** 使用 AES-256 加密 API Key
**And** 配置在"AI 模型设置"界面中可见
**And** 系统记录配置操作到审计日志

**相关需求：** FR13（添加云端模型提供商）、FR24（测试 AI 模型连接）、FR87（敏感数据加密）、FR89（审计日志）

### Story 1.4: 设置 AI 模型优先级和自动回退机制

作为用户，
我希望能够设置 AI 模型提供商的优先级并启用自动回退，
这样系统就能在首选模型不可用时自动切换到备用模型，确保爬取任务的连续性。

**Acceptance Criteria:**

**Given** 用户已配置多个 AI 模型提供商
**When** 用户在"AI 模型设置"界面
**Then** 系统显示所有已配置的模型提供商列表
**And** 每个提供商旁边显示优先级选择器（下拉菜单或数字输入）
**And** 用户可以为每个提供商设置优先级（1 = 最高优先级）

**Given** 用户在模型提供商列表中
**When** 用户修改提供商的优先级
**Then** 系统自动重新排序列表（按优先级顺序）
**And** 显示更新后的优先级顺序
**And** 保存优先级配置到本地配置文件

**Given** 用户在"AI 模型设置"界面
**When** 用户启用"自动回退到备用模型"选项
**Then** 系统保存回退机制配置
**And** 系统解释回退机制工作原理（例如：在首选模型失败时自动尝试优先级较低的模型）
**And** 用户可以为每个提供商配置回退超时时间（默认：5 秒）

**Given** 系统执行爬取任务
**When** 首选 AI 模型提供商在超时时间内无响应
**Then** 系统自动切换到优先级第二高的提供商
**And** 在任务日志中记录模型切换事件
**And** 用户界面显示模型切换通知

**Given** 所有 AI 模型提供商都不可用
**When** 系统尝试执行爬取任务
**Then** 任务进入"等待模型可用"状态
**And** 向用户显示错误消息："所有 AI 模型提供商当前不可用，请检查网络连接或配置"

**相关需求：** FR14（设置优先级）、FR18（自动回退到备用模型）、FR27（无缝切换模型）、FR51（99.9% 模型连接可用性）

### Story 1.5: 配置 AI 模型参数和成本预算

作为用户，
我希望能够配置 AI 模型的特定参数（temperature、max tokens 等）并设置每月成本预算，
这样我就能控制模型行为并避免意外的 API 调用费用。

**Acceptance Criteria:**

**Given** 用户在"AI 模型设置"界面
**When** 用户选择一个已配置的模型提供商
**Then** 系统显示提供商的参数配置面板
**And** 面板包含可配置参数：Temperature（滑动条：0.0-2.0）、Max Tokens（数字输入）、Top P（滑动条：0.0-1.0）
**And** 每个参数显示默认值和工具提示说明参数用途

**Given** 用户修改模型参数
**When** 用户点击"保存参数"按钮
**Then** 系统保存参数配置到提供商配置文件
**And** 配置在下次使用该提供商时生效
**And** 系统显示"参数已保存"确认消息

**Given** 用户使用云端 AI 模型提供商
**When** 用户在"成本管理"界面设置每月成本预算
**Then** 系统显示成本预算输入字段（货币单位）
**And** 用户可以设置预算警告阈值（例如：当达到预算的 80% 时发送警告）
**And** 系统保存成本预算配置

**Given** 用户设置了每月成本预算
**When** API 调用费用接近预算警告阈值
**Then** 系统在用户界面显示警告消息
**And** 警告消息显示当前费用、预算金额和剩余可用额度
**And** 用户可以选择继续使用或停止云模型调用

**Given** API 调用费用超过每月成本预算
**When** 系统尝试发起新的 API 请求
**Then** 系统拒绝请求并显示"已超过成本预算"错误消息
**And** 建议用户切换到本地模型或增加预算
**And** 系统发送预算超支通知

**相关需求：** FR15（配置模型参数）、FR19（查看实时 API 使用和成本）、FR20（设置每月成本预算）、FR21（成本优化建议）、FR58（准确成本追踪）

### Story 1.6: 配置数据隐私和脱敏选项

作为用户，
我希望能够配置数据隐私设置并启用数据脱敏，
这样我就能确保发送到云端 AI 模型的数据经过匿名化处理，保护敏感信息。

**Acceptance Criteria:**

**Given** 用户在"隐私和安全设置"界面
**When** 用户查看数据隐私配置选项
**Then** 系统显示"启用数据脱敏"复选框（默认未勾选）
**And** 系统显示脱敏策略选项：全部脱敏、仅脱敏电子邮件和电话、自定义脱敏字段
**And** 系统显示数据隐私警告说明："启用数据脱敏可保护敏感信息，但可能影响 AI 分析准确性"

**Given** 用户启用"数据脱敏"选项
**When** 系统准备将数据发送到云端 AI 模型
**Then** 系统在发送前对数据进行脱敏处理
**And** 敏感字段（如电子邮件、电话号码、信用卡号）被替换为占位符（例如：***@email.com）
**And** 脱敏操作在 500ms 内完成（对于 1MB 数据）

**Given** 用户使用云端 AI 模型且数据脱敏已启用
**When** 用户在界面中查看 AI 分析结果
**Then** 系统显示脱敏警告："已启用数据脱敏，某些信息可能不完整"
**And** 用户可以选择查看原始未脱敏数据（仅限本地存储的数据）

**Given** 用户在"隐私和安全设置"界面
**When** 用户更改数据隐私设置
**Then** 系统记录设置变更到审计日志
**And** 如果用户禁用了数据脱敏，系统显示确认对话框："禁用数据脱敏可能暴露敏感信息，是否确认？"
**And** 确认后保存设置

**相关需求：** FR22（启用/禁用数据脱敏）、FR23（数据隐私警告）、FR86（本地数据存储）、FR90（隐私设置配置）

### Story 1.7: 本地数据存储和安全设置

作为用户，
我希望能够配置本地数据存储路径并设置访问控制，
这样我就能掌控数据存储位置并确保只有授权用户能够访问应用。

**Acceptance Criteria:**

**Given** 用户在"系统设置"界面
**When** 用户访问"数据存储"配置部分
**Then** 系统显示当前数据存储路径
**And** 系统提供"更改存储路径"按钮
**And** 系统显示当前数据库大小和可用磁盘空间

**Given** 用户点击"更改存储路径"按钮
**When** 用户选择新的存储目录
**Then** 系统验证新目录的写入权限
**And** 系统显示数据迁移确认对话框（包括估计迁移时间）
**And** 用户确认后，系统将现有数据迁移到新目录
**And** 迁移完成后，系统更新存储路径配置

**Given** 用户在"安全和访问"设置界面
**Then** 系统显示访问控制选项
**And** 用户可以设置应用访问密码或启用系统认证（macOS Touch ID、Windows Hello）
**And** 用户可以配置自动锁屏时间（例如：5 分钟无操作后锁屏）

**Given** 用户设置了应用访问密码
**When** 用户重新启动应用
**Then** 系统显示密码输入界面
**Then** 用户输入正确密码后才能访问应用功能
**And** 连续 5 次输入错误密码后，系统锁定 30 秒（防暴力破解）

**相关需求：** FR86（本地数据存储）、FR87（敏感数据加密）、FR88（严格访问控制）、FR89（审计日志）

### Story 1.8: CLI 接口和界面偏好设置

作为高级用户，
我希望能够访问 CLI 接口并进行界面偏好设置，
这样我就能通过命令行执行高级操作并自定义用户界面体验。

**Acceptance Criteria:**

**Given** 用户是高级用户
**When** 用户在应用设置界面查看"高级功能"选项
**Then** 系统显示"启用 CLI 接口"选项
**And** 用户启用后，系统提供 CLI 访问说明和命令示例
**And** 系统在应用安装目录创建可执行 CLI 脚本

**Given** 用户启用 CLI 接口
**When** 用户在终端执行 CLI 命令（例如：`ai-crawler --list-tasks`）
**Then** 系统返回命令执行结果
**And** 支持的 CLI 命令包括：列出任务、启动任务、停止任务、查看日志、配置模型
**And** 所有 CLI 操作记录到审计日志

**Given** 用户在"界面偏好"设置界面
**When** 用户修改界面设置
**Then** 用户可以选择界面主题（浅色、深色、跟随系统）
**And** 用户可以设置界面语言（中文、英文）
**And** 用户可以配置显示密度（紧凑、标准、舒适）
**And** 用户可以启用或禁用动画效果
**And** 设置立即生效

**Given** 用户使用深色主题
**When** 系统显示任何界面
**Then** 所有界面元素符合深色主题设计规范
**And** 确保文字和背景对比度符合 WCAG 2.1 AA 标准

**相关需求：** FR35（CLI 接口访问）、FR36（自定义界面设置和偏好）、FR32（用户界面质量）
