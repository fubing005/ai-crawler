🤖 AI 爬虫框架 - 设计方向

三级视图策略：简洁 · 仪表板 · 专业

"输入网址 → AI 分析 → 获得数据"

🎯 核心设计原则

1. 零代码优先

核心价值完全不需要编程。所有主要功能都应通过鼠标点击完成。代码/CLI/API 仅作为高级选项供开发者使用。

2. AI 透明可见

不掩盖 AI 的局限性。让用户清楚理解 AI 在做什么、置信度如何、为什么做出某些判断。透明度建立信任。

3. 渐进式能力

从最简单的方式开始，高级功能在需要时才显示。支持三种用户类型：非技术分析师、数据工程师、开发者。

4. 即时反馈即信任

清晰的进度显示、状态更新、错误解释。用户在任何时候都知道正在发生什么，这建立了对系统的信任。

5. 首次体验即成功

80% 的注册用户应该在第一周内成功爬取至少一个网站。首次打开应用必须有清晰的引导、示例网址、简洁的配置流程。

📱 三级视图策略

应用提供三种不同的视图来服务不同类型的用户和使用场景。用户可以自由切换视图，系统会记住用户的偏好。

简洁视图（默认）

极致简洁，聚焦核心操作，像搜索引擎一样直观。适合首次用户、非技术用户和零代码体验场景。

🎯 聚焦核心

大搜索框居中，类似搜索引擎体验，最大程度突出 URL 输入框，减少干扰

🚀 快速开始

📱 响应式

🤔 为什么选择三级视图策略？

1. 满足所有用户类型

非技术用户：简洁视图，零代码体验。数据工程师：仪表板视图，监控和预览。开发者：专业视图，精确控制和批量操作。

2. 平衡简洁性和功能性

默认简洁，降低首次使用摩擦。高级功能可通过切换访问。用户可以根据需求选择最合适的视图。

3. 支持渐进式能力

用户从简单视图开始。随着使用经验增长，可以切换到更高级的视图。界面随用户技术水平自适应。

4. 解决核心设计挑战

渐进式复杂度：三个视图满足不同技术水平。AI 不确定性可视化：所有视图都有透明度特性。"黑盒"信任问题：实时预览和置信度显示建立信任。

5. 对齐核心体验原则

零代码优先：简洁视图最大化零代码体验。AI 透明可见：所有视图共享透明度特性。渐进式能力：三个视图支持渐进式能力。首次体验成功：首次使用向导 + 简洁视图。

🧩 组件策略

组件库：Naive UI

Vue 3 Composition API 原生。全面的组件集。优秀的 TypeScript 支持。内置暗色模式。强大的可访问性支持。

爬取进度组件

基于 Naive UI Progress。通过插槽添加爬取特定的状态和动画。未来扩展：暂停、恢复、取消操作。

AI 分析预览组件

基于 Naive UI Card 和 List。通过插槽添加字段高亮和置信度指示。未来扩展：多字段选择、字段关系可视化。

数据预览组件

基于 Naive UI Table。通过插槽支持排序、过滤、导出操作。未来扩展：批量编辑、数据合并。

♿ 可访问性标准

符合 WCAG 2.1 AA 标准，确保所有用户都能使用产品。

✅ 对比度标准

所有文本满足最小对比度比例。交互元素有清晰的焦点状态。颜色不作为唯一指示符。

✅ 键盘导航

所有交互元素支持键盘导航。清晰的焦点指示符。逻辑的 Tab 顺序。

✅ ARIA 标签

完整的 ARIA 支持供屏幕阅读器使用。语义化的 HTML 结构。所有控件都有描述性标签。

✅ 屏幕阅读器支持

所有图标都有文本替代。动态内容更新会被宣布。错误消息可访问。

🔍 AI 透明度实现

所有视图共享的透明度特性，让用户清楚理解 AI 的判断和不确定性。

1. 实时进度显示

AI 分析页面结构的进度。数据提取进度（已提取 X/Y 项）。预计剩余时间。

2. 字段预览和置信度

显示 AI 识别的字段列表。每个字段显示置信度（例如：95%）。支持字段预览。

3. 实时预览面板

中间区域显示预览面板。实时更新 AI 识别的结果。支持内联编辑和修正。

4. 任务日志

显示详细的执行日志。记录 AI 模型选择和切换事件。记录用户手动调整。

📊 成功流程 vs 失败流程

✅ 成功流程

打开应用 → 首次向导（选择 AI 模型）→ 输入网址 → AI 分析（3-5 秒）→ 预览识别的字段 → 修正字段（如需要）→ 开始爬取 → 实时查看进度 → 查看结果 → 导出数据

❌ 失败流程

打开应用 → 没有引导 → 输入网址 → AI 分析失败 → 模糊错误信息 → 用户感到沮丧 → 放弃

📴 离线模式支持

网络断开时，用户仍然可以访问历史数据，新任务会加入队列，网络恢复后自动执行。

🔴 离线状态指示

顶部状态栏显示离线状态。红色背景和图标。显示最后同步时间和队列任务数。

📡 离线队列管理

新任务自动加入队列。支持调整任务优先级（上移/下移）。可删除不需要的任务。

📁 本地数据访问

离线时仍可查看历史数据。支持搜索、筛选、导出本地数据。数据完全存储在本地。

🔄 自动同步

网络恢复后自动执行队列任务。显示同步进度。完成后更新统计信息。

↩️ 撤销/重做机制

支持撤销和重做操作，防止误操作导致数据丢失，提供安全感和控制感。

🎯 操作历史记录

记录所有可撤销操作。显示操作类型、时间、影响范围。支持查看操作详情。

⌨️ 快捷键支持

Ctrl/Cmd + Z：撤销。Ctrl/Cmd + Shift + Z：重做。Ctrl/Cmd + Y：重做。

🛡️ 选择性恢复

支持选择性撤销特定操作。可预览撤销效果。确认后执行撤销。

💾 历史持久化

操作历史持久化存储。重启应用后仍可撤销。支持清理历史记录。

💡 UX 模式分析和灵感

启发产品分析

🖥️ VSCode（开发者）

  • 优雅解决的问题：多功能开发环境，从简单到复杂都可以满足
  • 引导体验：欢迎界面 + 示例项目，快速上手
  • 导航和信息层级：左侧活动栏 + 资源管理器 + 编辑器区域
  • 创新交互：命令面板（Ctrl+Shift+P），快速访问所有功能
  • 视觉设计：深色模式、最小化 UI、专注代码
  • 错误处理：内联错误提示 + 问题面板，清晰的错误位置

🤖 ChatGPT（普通用户）

  • 优雅解决的问题：AI 对话界面，无需学习即可使用
  • 引导体验：空的聊天界面 + 示例问题，鼓励首次使用
  • 导航和信息层级：极简界面，只有一个输入框，所有复杂性隐藏
  • 创新交互：流式输出，实时看到 AI 的响应
  • 视觉设计：清爽、干净、聚焦内容
  • 错误处理：友好的错误提示，通常只是"重新生成"按钮

📊 Power BI（数据工程师/分析师）

  • 优雅解决的问题：数据可视化和分析，从数据到洞察
  • 引导体验：示例报告 + 拖拽式界面，降低学习曲线
  • 导航和信息层级：左侧报告选项卡 + 右侧可视化面板 + 底部数据
  • 创新交互：拖拽式可视化创建，即时预览
  • 视觉设计：专业、丰富、但不过于复杂
  • 错误处理：数据连接失败时的清晰指引

可迁移的 UX 模式

🧭 导航模式

  • 左侧活动栏 + 主内容区域（VSCode）
  • 简洁界面 + 隐藏复杂性（ChatGPT）
  • 示例模板引导（ChatGPT）

🎯 交互模式

  • 命令面板/快捷键（VSCode）
  • 流式输出（ChatGPT）
  • 拖拽式操作（Power BI）

🎨 视觉模式

  • 深色模式支持（三个产品都有）
  • 最小化、聚焦内容（VSCode/ChatGPT）
  • 专业但不复杂（Power BI）

反模式（要避免）

🚫 功能瀑布反模式

所有功能一次展示在界面上，用户感到不知所措。避免方式：渐进式披露，从核心功能开始。

🚫 专业术语轰炸反模式

错误信息或界面使用技术术语，非技术用户困惑。避免方式：用简单语言，提供解释或工具提示。

🚫 没有引导的新手陷阱

首次打开应用时没有明确指导，用户不知道从哪里开始。避免方式：清晰的首屏向导、示例网址。

🚫 黑盒 AI 反模式

AI 过程完全不透明，用户不知道正在发生什么。避免方式：显示 AI 分析过程、置信度、允许预览和修正。

🚫 缺乏反馈反模式

操作后没有视觉或状态反馈，用户不确定是否成功。避免方式：每个操作都有明确的视觉反馈。

  • 设计基础：简洁聚焦式
  • 界面特征：大搜索框居中，示例网址，收起式左侧栏
  • 目标用户：首次用户、非技术用户
  • 关键体验：零代码体验，"像搜索引擎一样简单"

  • 目标用户：数据工程师、有经验用户
  • 关键体验：数据透明，任务监控，快速访问

🔧 专业视图（开发者模式）

  • 设计基础：紧凑专业式
  • 界面特征：高密度信息展示，工具栏，详细配置面板
  • 目标用户：开发者、高级用户
  • 关键体验：效率优先，批量操作，详细配置

3. 支持渐进式能力

用户从简单视图开始。随着使用经验增长，可以切换到更高级的视图。界面随用户技术水平自适应。

4. 解决核心设计挑战

渐进式复杂度：三个视图满足不同技术水平。AI 不确定性可视化：所有视图都有透明度特性。

5. 对齐核心体验原则

零代码优先：简洁视图最大化零代码体验。AI 透明可见：所有视图共享透明度特性。首次体验成功：首次使用向导 + 简洁视图。

🛤️ 用户旅程流程

旅程 1: 首次使用旅程（新手用户）

旅程描述：首次启动应用，完成初始配置，成功爬取第一个网站

📋 流程设计问题

如何开始？
双击应用图标
需要什么信息？
欢迎页、AI 模型配置、首次爬取
需要什么决策？
选择 AI 模型、输入网址
如何知道进展？
步骤指示器、进度条
成功看起来像？
庆祝动画、数据统计
哪里可能卡住？
AI 模型选择、网址格式

✨ 优化方案

  • 最小化到价值的步数：示例网址让用户无需输入就能看到效果
  • 智能默认配置：检测本地 Ollama，自动推荐本地模型优先
  • 清晰进度指示：每个步骤都有明确的进度指示器（步骤 X/5）
  • 快速错误恢复：AI 模型连接失败时，提供具体的解决步骤
  • 庆祝时刻增强：首次成功爬取后显示庆祝动画和数据统计

旅程 2: 常规爬取旅程（已配置用户）

旅程描述：已配置用户输入网址，AI 分析并爬取数据

🎯 核心流程

输入网址 → AI 分析 → 预览字段 → 确认提取 → 查看结果 → 导出数据

⚡ 关键体验

实时进度显示、字段置信度指示、一键导出、准确率统计

🛡️ 错误处理

友好错误提示、重试选项、详细错误日志、解决建议

🔄 UX 一致性模式

确保整个应用的一致性体验，建立用户信任和熟悉感。

🎨 视觉一致性

统一的颜色系统、字体层级、间距规范。所有界面使用相同的设计令牌。

🖱️ 交互一致性

相同的操作有相同的反馈模式。按钮、表单、导航使用统一的交互模式。

📝 语言一致性

统一的术语和文案风格。错误信息、成功提示、操作说明使用一致的语言。

⌨️ 快捷键一致性

常用操作使用标准快捷键。Ctrl/Cmd + S 保存、Ctrl/Cmd + Z 撤销等。

🔔 反馈一致性

成功、错误、警告使用统一的视觉反馈。通知、提示、错误消息样式一致。

📱 响应式一致性

不同屏幕尺寸下保持一致的体验。移动端、平板、桌面端功能对等。

🎯 结论

这个设计方向为构建 AI 驱动的通用爬虫框架建立了清晰的基础，它具有以下特点：

简单
非技术用户的零代码体验
强大
开发者的 CLI、API、高级配置
透明
AI 操作的实时进度和置信度指示
自适应
三级视图策略适应不同技能水平
可访问
符合 WCAG 2.1 AA 标准
愉悦
情感设计和庆祝时刻
离线
网络断开时仍可使用，队列自动同步
安全
撤销/重做机制防止误操作

三级视图策略，结合渐进式披露和 AI 透明度，创造了一个从首次用户到高级开发者都能使用的体验，同时在每个级别都保持简洁和清晰。离线模式和撤销/重做机制进一步增强了用户体验的可靠性和安全性。
