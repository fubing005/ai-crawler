# Epic 9: 反爬虫机制与智能防护 (P0)

**用户价值：** 系统自动处理反爬虫机制（请求频率控制、User-Agent轮换、CAPTCHA），提高爬取成功率

**FR 覆盖：** FR57-FR66

**UX需求：** 错误反馈模式、错误处理和恢复

**Story 数量：** 6 Stories

---

## Story 9.1: 请求频率控制

作为反爬虫机制，
我希望控制请求频率避免被检测，
以提高爬取成功率。

**Acceptance Criteria:**

**Given** 任务执行中
**When** 向同一网站发送请求
**Then** 在请求之间添加随机延迟（2-5秒）
**And** 显示"等待中..."状态

**Given** 用户配置任务
**When** 设置频率限制
**Then** 支持自定义延迟范围（如 1-10秒）
**And** 提供推荐值（保守：5-10秒，激进：1-3秒）

**Given** 系统检测到网站限制
**When** 响应中包含速率限制头（如 Retry-After）
**Then** 自动遵守限制并等待指定时间
**And** 记录到日志

**Given** 多个任务并发执行
**When** 访问同一网站
**Then** 实施全局频率控制（共享延迟计时器）
**And** 避免同时发送请求

**Given** 用户查看任务统计
**When** 显示"遵守反爬虫规则"
**Then** 显示：总请求数、延迟总时长、平均延迟
**And** 提示"频率控制已启用"

**Requirements Covered:** FR57, NFR61
**Technical Constraints:** NFR6 (99.9%可用性)

## Story 9.2: User-Agent 旋转

作为反爬虫机制，
我希望为每个请求使用不同的 User-Agent 字符串，
以避免被单一 UA 识别。

**Acceptance Criteria:**

**Given** 系统发送请求到网站
**When** 选择 User-Agent
**Then** 从预定义的 UA 池中随机选择（NFR62）
**And** 包含常见浏览器的 UA（Chrome, Firefox, Safari, Edge）

**Given** 任务配置
**When** 用户设置"自定义 User-Agent"
**Then** 支持输入或粘贴自定义 UA 字符串
**And** 添加到 UA 池（标记为自定义）

**Given** UA 池包含多个选项
**When** 批量任务执行
**Then** 每个请求使用不同的 UA
**And** 记录每次请求使用的 UA 到日志

**Given** 用户查看反爬虫设置
**When** 进入"高级配置"
**Then** 显示当前 UA 池大小
**And** 支持"重置为默认池"选项

**Given** 检测到网站需要特定 UA
**When** 响应要求特定浏览器
**Then** 自动调整到兼容的 UA
**And** 记录调整原因

**Requirements Covered:** FR58, NFR62
**Technical Constraints:** NFR6 (99.9%可用性)

## Story 9.3: IP 轮换与代理池

作为反爬虫机制，
我希望使用 IP 轮换和代理池，
以避免 IP 被封禁。

**Acceptance Criteria:**

**Given** 用户配置代理池
**When** 进入"反爬虫设置"
**Then** 支持添加多个代理服务器（IP、端口、认证）
**And** 验证代理可用性

**Given** 任务执行中
**When** 发送请求
**Then** 从代理池中循环或随机选择代理（FR59）
**And** 跟踪每个代理的使用次数

**Given** 代理使用次数过多
**When** 检测到可能被封禁
**Then** 标记代理为"高风险"
**And** 自动切换到其他代理

**Given** 代理连接失败
**When** 无法连接到代理服务器
**Then** 标记代理为"不可用"
**And** 从池中暂时移除

**Given** 用户查看代理池状态
**When** 进入"代理管理"页面
**Then** 显示：可用数量、高风险数量、不可用数量
**And** 每个代理显示：IP、使用次数、最后使用时间、状态

**Given** 用户测试代理
**When** 选择代理并点击"测试"
**Then** 发送测试请求
**And** 显示响应时间和成功率

**Requirements Covered:** FR59, NFR63 (支持代理池配置)
**Technical Constraints:** NFR6 (99.9%可用性)

## Story 9.4: CAPTCHA 自动处理

作为反爬虫机制，
我希望自动识别和处理 CAPTCHA，
以继续爬取流程。

**Acceptance Criteria:**

**Given** 请求返回 CAPTCHA 挑战
**When** 系统检测到 CAPTCHA（图像、滑块、选择等）
**Then** 显示"检测到 CAPTCHA，正在处理..."提示
**And** 记录 CAPTCHA 类型到日志

**Given** 系统选择 CAPTCHA 处理方案
**When** 配置了 CAPTCHA 解决服务
**Then** 自动发送到第三方服务
**And** 显示处理进度

**Given** CAPTCHA 处理成功
**When** 收到解决方案
**Then** 自动提交答案
**And** 继续原请求流程

**Given** CAPTCHA 处理失败
**When** 多次尝试后仍失败
**Then** 标记任务为"需要人工干预"
**And** 显示"请手动解决 CAPTCHA"提示

**Given** 用户配置 CAPTCHA 设置
**When** 进入"反爬虫"高级选项
**Then** 显示可用的 CAPTCHA 服务列表
**And** 支持添加自定义服务 API

**Given** CAPTCHA 成功率统计
**When** 查看反爬虫报告
**Then** 显示 CAPTCHA 识别成功率（NFR64：90%）
**And** 显示失败次数和原因

**Requirements Covered:** FR60, NFR64
**Technical Constraints:** NFR6 (99.9%可用性)

## Story 9.5: 人类行为模拟

作为反爬虫机制，
我希望模拟人类浏览行为模式，
以降低被检测为机器的风险。

**Acceptance Criteria:**

**Given** 任务执行页面交互
**When** 需要模拟真实用户行为
**Then** 添加随机延迟（NFR65）
**And** 模拟鼠标移动轨迹（不是直接点击）

**Given** 页面需要滚动查看
**When** 内容在视口下方
**Then** 逐步滚动到目标位置（而非瞬间跳转）
**And** 滚动速度随机变化

**Given** 网站使用动态加载内容
**When** 检测到 AJAX 请求或 JavaScript 渲染（FR62）
**Then** 等待内容加载完成后再提取数据
**And** 使用 Playwright 的 `waitForSelector` 或 `waitForLoadState`
**And** 记录动态加载检测到日志

**Given** 单页应用（SPA）需要导航
**When** URL 改变但页面未完全重新加载（FR62）
**Then** 使用 Playwright 的路由和导航监听
**And** 等待 React/Vue/Angular 等框架完成渲染
**And** 支持 WebSocket 监听以捕获实时数据

**Given** 动态内容分批加载（无限滚动）
**When** 需要获取全部数据（FR62）
**Then** 自动滚动到底部触发加载
**And** 持续监听新元素出现
**And** 在达到指定页数或无新内容时停止

**Given** 动态加载超时
**When** 内容在预期时间内未出现（FR62）
**Then** 标记任务为"部分成功"
**And** 记录超时元素和等待时间
**And** 提供重试选项

**Given** 页面包含多个可交互元素
**When** 按顺序操作
**Then** 在元素之间添加随机延迟（0.5-2秒）
**And** 模拟人类犹豫和思考

**Given** 用户配置行为模拟
**When** 设置"模拟级别"
**Then** 提供：关闭、基础（随机延迟）、高级（鼠标轨迹、滚动）、真实（所有模拟）
**And** 显示每种级别的预期影响

**Given** 检测到异常检测系统
**When** 网站使用 JavaScript 分析用户行为
**Then** 自动启用高级模拟
**And** 记录检测到的原因

**Given** 用户查看任务日志
**When** 行为模拟激活
**Then** 显示"人类行为模拟已启用"标记
**And** 记录模拟行为类型和持续时间

**Requirements Covered:** FR61, FR62, NFR65
**Technical Constraints:** NFR6 (99.9%可用性)

## Story 9.6: 遵守规则与检测响应

作为反爬虫机制，
我希望自动遵守 robots.txt 和 Terms of Service，
同时检测并响应 IP 阻止。

**Acceptance Criteria:**

**Given** 任务开始执行
**When** 系统访问新网站
**Then** 自动获取并解析 robots.txt（FR63）
**And** 遵守定义的爬取规则（Disallow、Crawl-delay）

**Given** 用户配置任务
**When** 目标网站有明确的爬取策略
**Then** 检测 Terms of Service（FR64）
**And** 提示用户确认是否符合条款

**Given** 任务违反 robots.txt 规则
**When** 尝试访问禁止的路径
**Then** 自动跳过该路径
**And** 记录到日志并显示警告

**Given** 请求发送后
**When** 响应包含阻止信号（403, 429 等）
**Then** 系统检测到 IP 阻止（FR66）
**And** 暂停该网站的任务

**Given** 检测到 IP 阻止
**When** 自动响应机制触发
**Then** 启用回退策略（更换代理、增加延迟）
**And** 显示"检测到 IP 阻止，正在调整..."提示

**Given** 用户配置反爬虫设置
**When** 访问"反爬虫"配置页面
**Then** 显示遵守规则的开关
**And** 支持自定义违反策略（停止、继续、询问）

**Given** 系统监控反爬虫措施
**When** 检测到网站新增防御机制
**Then** 自动调整反爬虫策略
**And** 记录适应历史

**Given** 用户需要配置反爬虫设置
**When** 进入反爬虫配置页面（FR65）
**Then** 显示所有可配置的反爬虫选项
**And** 支持按网站或任务级别配置
**And** 提供预设配置模板（保守/标准/激进）

**Given** 用户配置反爬虫设置
**When** 调整请求频率、延迟范围、代理池等参数（FR65）
**Then** 实时预览配置对任务的影响
**And** 显示被检测风险级别评估
**And** 支持保存为自定义模板

**Given** 用户选择反爬虫配置模板
**When** 应用预设或自定义模板（FR65）
**Then** 批量应用到选中的任务
**And** 记录配置变更历史
**And** 提供一键恢复默认设置选项

**Given** 反爬虫配置修改
**When** 保存新的反爬虫设置（FR65）
**Then** 验证配置的有效性
**And** 显示配置摘要和应用范围
**And** 提示是否需要重启生效的任务

**Requirements Covered:** FR63, FR64, FR65, FR66
**Technical Constraints:** NFR6 (99.9%可用性)

## UI 设计规范 - 反爬虫配置

### 1. 请求频率控制UI

**设计基础：** 滑块控制 + 预设模式

- **频率滑块**：
  - 范围：1秒 - 30秒/请求
  - 显示当前值和推荐值区间
  - 颜色编码：绿色（安全）、黄色（中等）、红色（激进）

- **预设模式按钮组**：
  - "保守"：5-10秒延迟（绿色）
  - "标准"：2-5秒延迟（黄色）
  - "激进"：1-3秒延迟（红色）

- **实时预览区域**：
  - 显示"预计每小时请求数"
  - 显示"预计任务完成时间"
  - 显示"被检测风险级别"

### 2. User-Agent池配置UI

**设计基础：** 列表管理 + 添加/删除操作

- **UA池列表**：
  - 表格显示：类型（内置/自定义）、User-Agent字符串、使用次数、最后使用时间、状态
  - 操作列：测试、编辑、删除

- **添加UA对话框**：
  - 输入框：粘贴自定义UA字符串
  - 类型选择：内置浏览器类型（Chrome, Firefox, Safari, Edge）
  - 版本选择：最新版/特定版本

- **轮换策略选择**：
  - 单选按钮：随机轮换、顺序轮换、自定义权重
  - 预览：显示轮换顺序示例

### 3. 代理配置UI

**设计基础：** 代理池管理 + 连接测试

- **添加代理表单**：
  - IP地址、端口、用户名、密码
  - 代理类型选择：HTTP/HTTPS/SOCKS5
  - 代理池名称（用于组织）

- **代理池状态卡片**：
  - 统计：可用、高风险、不可用数量
  - 颜色指示：绿色（正常）、黄色（警告）、红色（失败）

- **测试代理功能**：
  - "测试连接"按钮
  - 显示：响应时间、成功率、最后测试时间
  - 刷新按钮：重新测试

- **使用日志表格**：
  - 显示：代理IP、使用次数、成功/失败、最后使用时间
  - 筛选：按状态、按代理池

### 4. 行为模拟UI

**设计基础：** 模拟级别选择 + 参数配置

- **模拟级别选择器**：
  - "关闭"：无额外延迟
  - "基础"：随机延迟0.5-2秒
  - "高级"：鼠标轨迹 + 滚动 + 延迟
  - "真实"：所有模拟 + 随机犹豫

- **延迟设置区域**：
  - 范围滑块：0.1秒 - 10秒
  - 随机性滑块：0% - 100%
  - 预览：显示典型延迟范围

- **滚动模式选择**：
  - "平滑滚动"：匀速滚动
  - "随机速度"：速度变化
  - "分步滚动"：分多次滚动

- **点击模拟开关**：
  - "启用鼠标轨迹"：显示移动路径
  - "启用随机偏移"：点击位置轻微随机
  - "启用延迟点击"：点击前暂停

### 6. 用户反馈与状态显示

- **状态指示器**：每个配置模块显示当前状态（已启用/已禁用）
- **实时统计**：显示当前任务的反爬虫效果（请求数、被阻止数、成功率）
- **建议提示**：根据配置显示优化建议
