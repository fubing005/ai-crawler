# Epic 4: 爬取任务管理和调度 - Stories

## Epic 概述

**目标：** 用户可以创建、调度、暂停、恢复和管理爬取任务，包括单个和批量 URL。

**用户成果：**
- 创建单个和批量 URL 爬取任务
- 调度任务（定时、频率）
- 暂停、恢复、取消任务
- 查看任务执行日志
- 组织任务到组或类别
- 实时查看爬取进度

**FRs 覆盖：**** FR30-FR33, FR47-FR56

---

## Story 1: URL 输入界面设计

**ID:** EPIC4-001

**优先级:** 高

**相关 FRs:** FR30

**用户故事：** 作为用户，我可以通过一个类似搜索引擎的简单界面输入 URL，以便快速开始数据爬取。

**描述：**
提供一个类似搜索引擎的 URL 输入界面，支持单 URL 和批量 URL 输入，具有简洁、直观的用户体验。

**Acceptance Criteria:**

1. **UI 界面要求**
   - [x] 首页提供明显的 URL 输入框，位置居中或顶部
   - [x] 输入框高度至少 48px，宽度至少 400px
   - [x] 输入框具有 placeholder 文本："输入网址开始爬取..."
   - [x] 提供"开始爬取"主按钮，具有明显的视觉样式
   - [x] 支持回车键触发"开始爬取"操作

2. **单 URL 输入功能**
   - [x] 支持输入单个 URL，格式包括 http:// 和 https://
   - [x] 自动补全 http:// 协议前缀（如果用户省略）
   - [x] 输入框支持粘贴 URL 操作
   - [x] 提供实时URL格式验证，无效 URL 显示错误提示
   - [x] URL 输入框最大长度限制为 2048 个字符

3. **批量 URL 输入功能**
   - [x] 提供"批量 URL"切换按钮或标签页
   - [x] 批量 URL 输入支持多行文本框（textarea）
   - [x] 每行一个 URL，最多支持 1000 个 URL
   - [x] 提供批量 URL 导入功能（从文本文件 .txt 或 .csv）
   - [x] 批量导入显示进度条和成功/失败统计

4. **URL 输入验证**
   - [x] 验证 URL 格式（RFC 3986 标准）
   - [x] 验证 URL 域名有效性（DNS 查询可选）
   - [x] 过滤重复的 URL，自动去重
   - [x] 提供无效 URL 列表和原因说明
   - [x] 显示有效 URL 数量统计

5. **快捷操作**
   - [x] 输入框右侧提供"清空"按钮
   - [x] 支持最近输入 URL 的历史记录（最近 10 条）
   - [x] 历史记录可通过下拉列表快速选择
   - [x] 提供 URL 模板预设（例如：电商网站、新闻网站）

6. **响应式设计**
   - [x] 输入界面在不同屏幕尺寸下保持可用性
   - [x] 移动端输入框宽度自适应
   - [x] 触摸设备提供键盘友好的界面

**技术要求：**
- 使用现代前端框架（React/Vue/Angular）
- URL 验证使用正则表达式和 HTML5 验证 API
- 历史记录存储在浏览器 localStorage
- 文件导入使用 FileReader API

- 实现任务状态机（待执行、执行中、暂停、完成、失败）
