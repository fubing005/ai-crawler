## 🚀 准备工作

### 步骤 1：创建新的 Figma 文件

1. 打开 Figma 桌面应用
2. 点击 `+` 创建新文件
3. 重命名文件为：`AI 爬虫 - 线框图设计`

### 步骤 2：创建页面结构

在左侧面板为每个主要功能创建独立的页面：

1. 点击左侧 `Pages` 区域的 `+` 按钮
2. 创建以下页面（按顺序）：
   - `01-设计系统基础` - 颜色、字体、变量
   - `02-组件库` - 按钮、输入框、卡片等
   - `03-首次使用向导`
   - `04-主界面`
   - `05-新建爬虫流程`
   - `06-数据预览和导出`
   - `07-设置和历史`

## 🎨 创建设计系统

### 在 `01-设计系统基础` 页面创建

#### 1. 创建颜色变量集合

1. 打开右侧面板的 `Local Variables`
2. 点击 `+` 创建新的变量集合，命名为 `AI Crawler Colors`
3. 重命名默认模式为 `Light Mode`

#### 2. 创建颜色变量

创建以下颜色变量（所有类型设置为 `COLOR`）：

**品牌色：**
```
primary-blue      #3182CE  (主蓝色)
secondary-blue    #63B3ED  (辅助蓝色)
ai-purple         #805AD5  (AI 紫色)
```

**语义色：**
```
success-green     #48BB78  (成功)
warning-yellow    #ECC94B  (警告)
error-red         #F56565  (错误)
```

**中性色：**
```
text-primary     . #1A202C  (文字主色)
text-secondary    #4A5568  (文字次色)
text-gray        #718096  (文字灰)
bg-white         #FFFFFF 1 (背景白)
bg-gray          #F7FAFC  (背景灰)
border-gray      #E2E8F0  (边框灰)
```

**变量作用域设置：**
- 品牌色和语义色：`FRAME_FILL`, `SHAPE_FILL`, `TEXT_FILL`
- 中性色：`FRAME_FILL`, `SHAPE_FILL`, ` `TEXT_FILL`, `STROKE_FILL`

#### 3. 创建间距变量集合

1. 创建新变量集合 `AI Crawler Spacing`
2. 创建以下 FLOAT 类型变量：

```
space-4        4px   (超小间距)
space-8        8px   (小间距)
space-16       16px  (标准间距)
space-24       24px  (中间距)
space-32       32px  (大间距)
space-48       48px  (超大间距)
```

**作用域：** `GAP`, `WIDTH_HEIGHT`, `CORNER_RADIUS`

#### 4. 创建圆角变量集合

1. 创建新变量集合 `AI Crawler Radii`
2. 创建以下 FLOAT 类型变量：

```
radius-sm      4px   (小圆角)
radius-md      8px   (中圆角)
radius-lg      12px  (大圆角)
```

**作用域：** `CORNER_RADIUS`

#### 5. 创建文字样式

打开右侧 `Local Text Styles`，创建以下样式：

**标题：**
```
Display Large  24px  SemiBold  line-height: 32px
Display Medium 20px  SemiBold  line-height: 28px
Display Small 18px  SemiBold  line-height: 24px
```

**正文：**
```
Body Large     16px  Regular   line-height: 24px
Body Medium    14px  Regular   line-height: 20px
Body Small     12px  Regular   line-height: 16px
```

**辅助文字：**
```
Caption        12px  Regular   line-height: 16px
Overline       10px  Medium    line-height: 14px
```

## 🧩 创建基础组件

### 在 `02-组件库` 页面创建

#### 1. 按钮组件

创建 3 个按钮变体：

**主要按钮（Primary Button）**
- 尺寸：`200px × 48px`
- 背景：`primary-blue` 颜色变量
- 文字颜色：白色
- 圆角：`4px`（radius-sm）
- 文字样式：`Body Medium`
- 字重：`SemiBold`
- 内边距：`12px`

**次要按钮（Secondary Button）**
- 尺寸：`200px × 48px`
- 背景：白色
- 边框：`1px solid #3182CE`
- 文字颜色：`primary-blue`
- 圆角：`4px`（radius-sm）
- 文字样式：`Body Medium`

**小型按钮（Small Button）**
- 尺寸：`120px × 32px`
- 其他样式同主要按钮

将它们组合为 `Button` 组件集（Component Set），变体属性：
- `variant`: primary | secondary
- `size`: large | medium | small

#### 2. 输入框组件

**文本输入框**
- 高度：`48px`
- 背景：白色
- 边框：`1px solid #E2E8F0`（border-gray）
- 圆角：`4px`（radius-sm）
- 内边距：`16px`（space-16）
- 占位符文字颜色：`#A0AEC0`
- 文字样式：`Body Medium`

**状态变体：**
- default（默认）：灰色边框
- focus（聚焦）：蓝色边框，2px
- error（错误）：红色边框，1px
- disabled（禁用）：灰色背景

#### 3. 卡片组件

**标准卡片（Card）**
- 内边距：`24px`（space-24）
- 背景：白色
- 圆角：`12px`（radius-lg）
- 阴影：`0 4px 6px -1px rgba(0, 0, 0, 0.1)`
- 边框：1px solid #E2E8F0

**AI 推荐卡片（AI Recommendation Card）**
- 内边距：`24px`
- 背景：渐变 `linear-gradient(135deg, #3182CE 0%, #805AD5 100%)`
- 圆角：`12px`
- 文字颜色：白色
- 阴影：`0 8px 16px -4px rgba(49, 130, 206, 0.3)`

#### 4. 导航栏组件

**顶部导航栏**
- 高度：`64px`
- 背景：白色
- 边框：底部 `1px solid #E2E8F0`
- 布局：水平，space-between
- 左侧：Logo + 导航菜单（间距 `32px`）
- 右侧：用户头像/下拉菜单

#### 5. 进度条组件

**进度条**
- 高度：`24px`
- 背景颜色：`#F7FAFC`（bg-gray）
- 填充颜色：`primary-blue`
- 圆角：`4px`

#### 6. 表格组件

**数据表格**
- 背景颜色：白色
- 边框：`1px solid #E2E8F0`
- 圆角：`8px`

**表头行：**
- 高度：`48px`
- 背景颜色：`#F7FAFC`
- 文字样式：`Body Medium`，SemiBold
- 文字颜色：`text-secondary`

**数据行：**
- 高度：`48px`
- 背景颜色：白色（交替行：`#F7FAFC`）
- 文字样式：`Body Medium`
- 文字颜色：`text-primary`
