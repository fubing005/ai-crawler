# 技术上下文

## 技术栈
- **编程语言**：Python
- **部署方式**：本地部署（非云端、非 SaaS）
- **数据存储**：本地文件系统
- **数据组织**：按不同数据来源自动存储到不同文件夹

## AI 能力细节
- **基础**：基于预训练的大语言模型，经过网页结构理解任务的微调
- **识别范围**：能够识别常见的页面模式（商品列表、文章详情、用户资料等）
- **自适应能力**：当网站结构发生适度变化时，AI 能够自适应调整
- **限制**：对于完全重构的网站或罕见的页面类型，可能需要用户提供少量示例进行学习
- **成本考虑**：大模型推理成本需要控制，可能需要优化或使用更小的模型

## 反爬虫机制
- **基础反爬虫**（MVP 包含）：
  - 请求频率控制（避免触发速率限制）
  - User-Agent 轮换（模拟不同浏览器）
  - 随机延迟（模拟人类行为）
  - AI 识别常见反爬虫触发条件（验证码页面、IP 封禁提示）
- **高级反爬虫**（MVP 不包含）：
  - 复杂验证码破解
  - IP 代理池
  - 行为分析模拟
  - 可能需要人工配置或第三方服务

## 用户界面
- **类型**：Web 界面
- **设计原则**：简单易懂
- **目标**：降低学习曲线，让非技术用户也能使用

## 数据导出
- **支持格式**：JSON、CSV
- **目的**：方便集成到现有的数据处理管道中

## 合规性
- **数据隐私**：满足 GDPR、CCPA 等数据隐私法规要求
- **网站合规**：用户可以完全控制爬取行为，遵守目标网站的服务条款和 robots.txt 规范

# 用户场景

## 开发者场景
- **痛点**：使用 Scrapy，每个新网站都要从头开始，无法复用代码
- **需求**：API 易用性和扩展性
- **成功标准**：在几分钟内完成新网站的爬取，而不是数小时或数天
- **顿悟时刻**：第一次成功爬取新网站而无需编写代码时

## 数据工程师场景
- **痛点**：维护多个爬虫的调度和监控，确保数据质量和一致性
- **需求**：数据质量和调度
- **成功标准**：获得高质量、结构化的数据，能够轻松集成到 ETL 流程中
- **顿悟时刻**：第一次成功爬取新网站而无需编写代码时

## 工作流集成
- **使用方式**：作为独立工具使用
- **集成方式**：可以导出数据到其他系统
- **典型流程**：网址 → AI 分析 → 数据提取 → 导出为 JSON/CSV → 集成到数据处理管道

# 竞争情报

## 现有工具
- **Scrapy**：成熟的 Python 爬虫框架，但需要手动编写选择器
- **Puppeteer/Playwright**：支持动态页面，但维护成本高
- **BeautifulSoup**：简单易用，但不支持动态页面和智能学习
- **Octoparse**：可视化爬虫工具，但功能有限且价格昂贵

## 市场背景
- **需求增长**：数据采集需求持续增长，电商、金融、媒体等行业需求旺盛
- **技术突破**：AI 大模型在网页理解方面取得突破
- **用户需求**：开发者对低维护成本的爬虫解决方案需求强烈

## 用户情绪
- **主要抱怨**：
  - 传统爬虫维护成本高，网站结构变化导致频繁失败
  - 手动编写选择器耗时耗力
  - 缺乏智能化的爬虫工具

## 时机和机会
- **技术驱动**：AI 大模型在网页理解方面取得突破
- **市场接受度**：开发者对 AI 辅助开发工具接受度高
- **市场空白**：市场缺乏真正智能化的通用爬虫框架

## 风险和考虑
- **反爬虫机制**：日益复杂，需要持续应对
- **数据隐私**：合规性要求越来越高
- **竞争压力**：与现有工具的竞争

# 需求提示

## 功能需求
- AI 必须能够自动识别页面结构
- AI 必须能够理解页面语义
- 必须支持常见数据类型（商品信息、文章内容、用户资料等）
- 必须支持数据导出为 JSON 和 CSV 格式
- 必须提供简单易用的 Web 界面
- 必须支持本地部署和数据存储
- 必须按不同数据来源组织存储

## 非功能需求
- 爬取成功率目标：70-80% 的常见网站类型首次爬取成功
- 用户满意度目标：NPS 达到 50+
- 用户采用率目标：80% 的注册用户在第一周内成功爬取至少一个网站
- 维护成本降低目标：与传统爬虫相比，维护时间减少 70% 以上

## 技术约束
- 必须使用 Python
- 必须支持本地部署
- 必须支持本地文件存储
- 必须遵守目标网站的服务条款和 robots.txt 规范
- 必须满足 GDPR、CCPA 等数据隐私法规要求

## 合规性需求
- 必须提供数据隐私保护
- 必须允许用户完全控制爬取行为
- 必须支持遵守 robots.txt 规范
- 必须支持遵守目标网站的服务条款
